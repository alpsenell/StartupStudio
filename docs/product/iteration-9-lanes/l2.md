# L2 — A life score, a second board, and a seventh ending

*Branch `l2-lifescore`, cut from `scaffold-9`. Iteration 9, the Life tab.*

## What I built

### The number

`LifeScore.score(_:balance:) -> Int` grades the founder's life 0…100 as a
pure function of the state, and `LifeScore.breakdown(state:balance:)`
returns the same thing as seven `Component`s (label, points, max, one line
of fact, one line of advice) so a screen can draw it as bars and say what
would raise it.

`LifeScore.biggestGap(state:balance:)` picks the component with the most
points still on the table — the single sentence a score needs.

**It is display-only.** No system reads it, the pacing bots never see it,
and the only place it feeds back into the simulation is the gate on the
new ending, which the founder has to press. No new `rng` / `worldRNG`
draws — no draws at all; the whole thing is arithmetic on state.

### The seventh ending

`EndingKind.walkedAway`, headline **"Walked away"**, `isSuccess == true`.
Action `.walkAway`; gated by `GameState.canWalkAway(balance:)` and
explained by `GameState.walkAwayBlocker(balance:)`, exactly the shape
`canStayIndependent` / `independenceBlocker` already had, so the button
says why before it is pressed.

**It cannot be played past.** `Reducer.continueAfterEnding` still takes
`.ipo` and `.independent` only, and I left it that way deliberately: the
founder is not there any more, and a *Keep running it* button under this
headline would be the screen arguing with itself. `EpilogueCopy`'s
fallback arm names `.walkedAway` among the endings that never continue.

## The weights and the gates I chose

`BalanceConfig.lifeScore` (`Balance/BalanceConfig+LifeScore.swift`, and a
`"lifeScore"` block in `Balance.json`). The six maxima sum to exactly 100;
the penalty takes up to 15 off and the total is clamped to 0…100.

| Component | Max | How |
|---|---|---|
| Partner | 22 | `max × stageWeight × affection/100`; stage weights single 0, dating 0.5, partner 0.8, married 1.0 |
| Children | 15 | `max × min(count,2)/2 × keptFactor`; `keptFactor` is 1 with no missed family date, drops to 0.45 the day one is missed and climbs back over 364 days |
| Health and energy | 22 | `max × (0.6·health + 0.4·energy)/100` |
| Friends | 12 | `max × min(1, Σbond / 240)` — reads `state.life.friends.friends`, which is empty until L4, so this reads 0 today |
| Evenings on people | 19 | `max × min(1, n/24)` over the last 364 days of the journal |
| Home | 10 | `max × tierRank/3` |
| **What it cost** | −15 cap | −4 a burnout, −3 a hospital stay, −8 for a chronic condition |

*Evenings on people* counts `.partnerTime`, `.hungOutWith`,
`.employeeMentored` and a `.weekendSpent` on `dateNight` / `friends` /
`familyTime` — an evening at the gym or on a course is an evening, it is
just not an evening spent on anybody.

**Walked away**, all six must hold:

| Gate | Default |
|---|---|
| Days in | `walkAwayMinDay = 546` — a year and a half. The copy counts in **weeks** (78, and "N more weeks" in the refusal): the game's year is 364 days, so integer years would render 546 as "1 year" |
| No debt | `company.cash >= 0 && loanBalance <= 0` |
| No board | `!investors.hasBoard` (a bought-out round is not seated, so buying the board out opens it) |
| Somebody to hand it to | `headcount > 1` |
| Net worth | `walkAwayMinNetWorth = $250,000` |
| Life score | `walkAwayMinLifeScore = 60` |

The ending's reason quotes both numbers and names the successor:
> "You left Northgate standing after 3 years, 7 people on payroll, Mika
> Alvarez holding the keys. $412,000 behind you and a life at 71. Nobody
> made you."

## Deviations from the brief, and why

1. **No new `GameEvent` case for walking away.** `stayedIndependent` has
   one, but a seventh case means editing `GameEvent`'s `severity` switch,
   which sits outside every lane's markers in a file six other lanes are
   also touching. The ending's `kind` is what the feed, the biography and
   Game Center all read, so nothing is lost. If the PM wants a journal
   line, it is a three-line follow-up after the merge.

2. **`Balance.json` gained a `"lifeScore"` key.** The scaffold's comment
   in `BalanceConfig.swift` says an inline default keeps a block's key
   optional; it does not — Swift's synthesized `Decodable` still calls
   `decode`, and every previous "optional" block is in fact present in
   `Balance.json`. The engine suite failed loudly until I added the key.
   The struct's own decoder is `decodeIfPresent` throughout, so a
   *rebalanced* file may omit any field. **L5 and L6 will hit the same
   thing** — a `BalanceConfig+X.swift` alone is not enough, the block has
   to exist in `Balance.json`. I appended mine at the end after
   `"origins"`, behind an `"_iteration9Blocks"` note, so later lanes
   append after me.

3. **The front door shows no life score.** The brief lists the front door
   among the places the number should sit next to net worth, but the
   front door never shows net worth — a save slot is company, founder,
   day, chapter and ending. Putting one there means a new field on
   `SaveSummary` in `TycoonSave`, which is not L2's file. Left out; noted
   as a follow-up below. The Dynasty room's run rows, which *do* carry a
   finished run's numbers, got it instead.

4. **`PostMortem.swift` is unchanged.** It has no switch over
   `EndingKind`, and the biography only renders it for
   `!info.kind.isSuccess`. *Walked away* is a success, so there is
   nothing to write there.

5. **No seventh earned look on the front door.** `Unlocks.earnedLooks`
   pairs each ending with a curated face seed, and a seventh entry would
   re-pin a count *and* change what the new-game look picker renders in a
   snapshot test — for a cosmetic reward I cannot eyeball a good seed for.
   Left as a follow-up.

6. **The evenings window is really "as far back as the journal reaches".**
   `state.eventLog` keeps 500 entries, which on a busy year is less than
   364 days. Full marks are at 24 evenings, a low enough bar that the cap
   almost never bites, and the log is the only record of *who* an evening
   went to. Said so in the doc comment.

## Follow-ups I need in files I do not own

1. **`TycoonSave.SaveSummary`** — a `lifeScore: Int?` field, set in
   `SaveSummary.init(state:)`, so the front door's Continue card and slot
   picker can carry the second number the way they carry the ending.
2. **`Unlocks.earnedLooks`** (front door / new-game flow) — a seventh
   curated face seed for `.walkedAway`, plus the count re-pin in
   `CustomCompanyTests`.
3. **L3 (children).** `LifeScore`'s children component uses a proxy —
   days since the last `familyDateMissed` — because there is no bond yet.
   When `Child.bond` lands, swap `keptDaysFactor` for the mean bond; the
   balance keys `missedDateFloor` / `missedDateRecoveryDays` can go.
4. **L4 (friends).** The friends component reads
   `state.life.friends.friends` and scores `Σbond / 240` — three friends
   at 80. If L4's bonds sit on a different scale, retune
   `friendsBondForFullMarks`, not the max.
5. **L6 (sabbatical).** A founder who is *away* should probably not be
   able to walk away in the same breath; if `SabbaticalState` lands with
   an "is away right now" predicate, add it to `walkAwayBlocker`.
6. **L5 / L6 balance blocks.** See deviation 2: add the JSON key too, or
   the whole engine suite fails on `keyNotFound`.

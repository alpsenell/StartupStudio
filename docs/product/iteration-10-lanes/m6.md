# M6 — The bug hunt

*Branch `m6-bughunt`, cut from `scaffold-10`. Simulator `ws-l6`.*

During a build, bugs crawl on the floor in front of the desks of the people
working on it, and a thumb squashes one. Three a day, a chirp, a knock and a
splat. Nothing spawns unless `openBugs` is already above zero, no bot ever
taps, and a run that never opens HQ is the run that shipped.

## What was built

### Engine

- **`BugHunt.swift`** — the rules, and the only place they live.
  `isHuntable(_:)` (in development, `codePts >= 1`, `openBugs > 0`),
  `huntableBuilds(in:)`, `squashesToday(in:)`, `squashesLeft(in:balance:)`
  and `refusal(productID:in:balance:)`, which returns a
  `BugHunt.Refusal` carrying the sentence the player is shown. Both the
  reducer and the app ask the same function, so the reason on screen is the
  reason the engine used.
- **`ProductSystem.squash(productID:state:balance:)`**, one function in a
  `// MARK: Iteration 10 — M6` region at the very end of the file (M1 owns
  the rest of it; nothing else in it was touched). Decrements `openBugs` by
  one and returns `.bugSquashed`.
- **`.squashBug(productID:)`** in `GameAction`'s M6 region, handled in
  `Reducer.apply`'s M6 region. No system, no tick, no rng draw.
- **`.bugSquashed(productID:remaining:day:)`** in `GameEvent`'s M6 region,
  graded `.quiet`, with copy in `EventCopy` ("Squashed a bug in Bug Farm —
  9 to go" / "Caught the last bug in Bug Farm yourself").
- **`BalanceConfig+BugHunt.swift`** with `perDay` (3) and `maxOnScreen` (3),
  the matching `"bugHunt"` object appended after `"sabbatical"` in
  `Balance.json`, and a `KeyedDecodingContainer` overload so an older
  balance file with no such key still decodes.

### PixelKit

- **`OfficeFXSprites.bug()`** — 10×9, four frames (two walking, two paused),
  palette-only: `Palettes.outline`, `ink[3]` for legs and antennae,
  `moss[2]` shell, `moss[4]` for the wing-case seam, `ember[1]` for the eye.
  The seam is what stops it reading as a green lozenge at phone size.
- **`OfficeFXSprites.bugSplat()`** — 11×6, two frames (the burst, then the
  bits settling), `moss[1..3]`.
- **`OfficeFX`**: `bugLoop`, `bugFrame`, `bugs(_:tier:at:)` and
  `merging(bugs:into:tier:at:)`. A bug patrols a four-leg loop on the floor
  strip in front of its desk; the legs are whole seconds long so a leg never
  changes inside the director's one-second bucket, and each leg is emitted
  as an absolute `Motion` so the 12 fps renderer interpolates it without a
  recompose. `merging` slots each bug into the director's already-sorted
  list at its own depth, so an empty list returns the room untouched.
- **`OfficeBug`** (`id`, `seat`, `isSquashed`), `Sendable`/`Hashable`.
- **`OfficeHitRegion.Kind.bug(Int)`**, produced by `OfficeDirector
  .bugRegions(input:at:)` from the same `bugFrame`, padded out to at least
  16×14 scene pixels and given priority 3 — while a bug is out, the bug is
  what the finger meant.
- **`OfficeSceneInput.bugs: [OfficeBug] = []`** (defaulted, in a marked
  region), and `OfficeSceneView`'s compose closure merges them in. Every
  existing caller, preview and frame sheet draws exactly what it drew.

### App

- **`OfficeCard`**: `bugs`/`nextBugID` state, a `.task` that runs
  `BugHuntSpawner.advance` four times a second, a `bugsForPreview` hook for
  snapshots, and `handleTap` intercepting `.bug` before
  `OfficeTapDestination`. A landed squash plays `Haptics.squash()` (`.rigid`
  — the sharpest impact iOS has) and `Sounds.play(.squash)`, sends the
  action and leaves the splat on the floor for 0.55s. A refused one plays a
  warning haptic and a toast with the refusal's sentence.
- **`BugHuntBug` / `BugHuntSpawner`** in `OfficeTaps.swift`'s M6 region:
  sweeps splats, drops bugs off builds that shipped or went clean, and lets
  one more in at a time (three at once read as an infestation; one, then
  another, reads as a build going wrong while you watch). Desks come from
  PixelKit's own `OfficeBehaviors.seating`, so a bug is at the desk the
  player can see that person sitting at; never two on one desk.
- **`SoundEffect.squash`** — two 22 ms square blips at 2093 and 2637 Hz
  (higher than anything else in the game) then a 70 ms low triangle at
  147 Hz that the shared exponential decay cuts off: up-up-*thud*, over in
  eleven hundredths of a second.
- **`JournalBuilder.isRoutine`** learns `.bugSquashed`, so fifteen squashes
  a week fold into the week's one routine line.
- **`-autoBugs`** in `DebugLaunch`'s M6 region: starts a code-heavy build,
  hires one person, puts everybody on it, answers prompts (never a buyout),
  and stops the clock the moment a build has an open bug and the room has a
  team. `-autoBugs splat` draws every bug as the splat and holds it, because
  a simulator cannot tap — display only, nothing is sent.

## The cap and the spawn rules

- **Cap: three a day, across every build** (`balance.bugHunt.perDay`),
  counted by scanning the event log backwards for `.bugSquashed` entries
  whose `day` is today.
- **Spawn:** a bug exists on screen only while some product is in
  development with `codePts >= 1` and `openBugs > 0`. At most
  `maxOnScreen` (3) live at once, at most one per desk, one new bug per
  250 ms tick, on the desks of the people assigned to that build (the
  founder's own desk when nobody else is on it).
- **Bugs keep crawling after the cap is spent**, so the refusal has
  something to refuse: a fourth tap says *"That's today's lot. The team gets
  the rest — sleep on it."*
- **Refusals**: no such build / already shipped / not yet coding / nothing
  to squash / daily cap reached, each with its own sentence.
- **Neutrality**: no field was added to any saved type, no `rng` or
  `worldRNG` draw was added, no system runs on a tick, and no bot taps. A
  balance file with no `"bugHunt"` key still loads.

## Deviations from the brief

1. **The day's tally is derived from the event log, not stored on
   `DevProgress`.** The brief offered a counter on `DevProgress` with
   decode-if-present / encode-when-non-zero. `DevProgress`'s Codable has a
   hand-written decoder but a *synthesized* encoder, so a new coding key
   would be written for every build in every save — which is exactly what
   the byte-identical fixtures forbid — and fixing that would have meant
   rewriting the encoder inside `Product.swift`, which M1 owns and is
   editing. Scanning the log backwards for today's `.bugSquashed` entries is
   exact (500-entry log, three a day), costs nothing, survives save/load,
   and touches neither `Product.swift` nor any save format. **M1's
   `Product.swift` was not modified at all.**
2. **One line outside my markers**: `case .bugSquashed: .quiet` in
   `GameState.severity`, immediately before its `default:`, under a
   `// MARK: Iteration 10 — M6` comment. The switch has no per-lane regions
   and its `default` is `.info`, which would have put a toast, a sound and a
   haptic on every squash on top of the chirp and the splat. Flagged here as
   rule 10 asks.
3. **The journal fold went in `JournalCard.swift`, not
   `JournalScreen.swift`.** `JournalBuilder.collapsingRoutine` and its
   `isRoutine` live in `JournalCard.swift`; `JournalScreen` only calls them.
   Marked region, one case added.
4. **Bugs crawl on the floor strip in front of the desk, not across the
   desktop.** The desktop is under a monitor and behind whoever is sitting
   at it; a bug you cannot see is a bug you cannot squash. It is two pixels
   from the drawers and still reads as their desk.
5. **The bug is drawn over the furniture** (`zIndex` + 2000, still under the
   hour's colour wash). Half-hidden behind a stack of boxes it was
   unfindable — and unlike everything else in that room it is gone in a few
   seconds.
6. **No PixelKit baseline needed re-pinning.** All 336 tests pass unchanged;
   no existing test input carries a bug, so every composed scene is
   byte-identical.

## Follow-ups

- **`Toast.shouldToast`** (`App/Sources/Components/Toast.swift`) could list
  `.bugSquashed` explicitly instead of relying on `.quiet`; I left that file
  alone. If a later lane makes the severity switch region-aware, deviation 2
  can be folded into an M6 region.
- **The bug sprite draws over people.** At `zIndex + 2000` a bug is in front
  of somebody standing between it and the viewer. It is the right trade for
  findability, but if the room ever gets a proper foreground layer the bug
  belongs in it.
- **Campus scale.** On a campus scene (260 scene px wide) one scene pixel is
  about one point on a phone, so the bug is roughly 10×9 pt with a 16×14
  hit region. It is still tappable but small; a per-tier sprite scale, or
  putting bugs only on the nearest desk row at that tier, would help.
- **`OfficeDirector.compose` does not draw bugs.** They are merged in
  `OfficeSceneView`, because `OfficeDirector.swift` is not this lane's file.
  If the PM wants bugs in the PNG frame sheets, moving the merge into
  `build()` is a three-line change.
- **No pressed state for a bug.** A bug dies on the tap, so the press
  outline never had time to matter; if the tap ever becomes a hold, it will.
